# 第1章 绪论

<a id="section-1-1"></a>
## 1.1 为什么学习数字图像处理

图像能记录场景、呈现难以直接观察的对象，并为人和机器提供丰富的信息。例如，显微成像使微小结构可见，遥感图像使大范围地表可分析，机器人用图像判断目标位置和环境变化。

数字图像处理的两个主要目的：

1. **改善供人观察的视觉效果**：调整亮度和对比度、抑制噪声、突出细节。
2. **为机器分析提供合适的数据**：分割目标、提取特征、识别类别、估计几何关系。

对于特定任务的要求，应当采用对应的方法。例如，锐化可能使边缘更醒目，却改变边缘附近的数值；去噪可能改善观看体验，却抹掉微弱小目标。

<a id="section-1-2"></a>
## 1.2 什么是图像与数字图像

### 1.2.1 二维函数模型

灰度图像通常表示为二维函数：

$$
f(x,y).
$$

$(x,y)$是位置，$f(x,y)$是该位置的强度。彩色图像则用向量表示，例如：

$$
\mathbf f(x,y)=\begin{bmatrix}R(x,y)\\G(x,y)\\B(x,y)\end{bmatrix}.
$$

图像通常是场景的二维投影或某种物理量的二维表示，不等于场景本身。深度、遮挡、照明和成像设备都会影响图像。

### 1.2.2 模拟图像与数字图像

- 模拟图像模型：空间坐标和强度连续。
- 数字图像：空间坐标离散，并将强度用有限精度表示。
- 像素：数字图像的基本采样元素，具有位置及一个或多个数值。

e.g.普通8位灰度图像有256个灰度级，但每个值均可用二进制编码。

**补充**：数字图像也可以使用浮点数组。这里“数字”指用有限精度数字表示，不要求处理过程中的像素只能取整数。

### 1.2.3 位图与矢量图形

| 比较 | 位图图像 | 矢量图形 |
|---|---|---|
| 基本描述 | 像素阵列 | 点、线、曲线、形状与绘制参数 |
| 放大表现 | 可能暴露像素块或插值模糊 | 可重新按目标分辨率绘制 |
| 常见用途 | 摄影、医学图像、遥感图像 | 图标、工程绘图、字体轮廓 |

### 1.2.4 图像分类

从不同维度分类：

- 按数值表达：二值、灰度、RGB、多通道。
- 按视觉呈现：真彩色、伪彩色。
- 按成像波段：可见光、红外、X射线、微波等。
- 按应用来源：医学、遥感、显微、工业检测等。

二值图像只有两个取值；黑白照片通常是多级灰度图像。伪彩色则把原始灰度或其他测量值映射成颜色，颜色不一定对应真实物体颜色。

<a id="section-1-3"></a>
## 1.3 数字图像处理的含义与发展

数字图像处理利用数字计算设备对图像进行数学、逻辑或统计运算。它不仅改变图像显示，还可以产生区域、边界、特征或其他描述。

历史脉络：

1. 早期通过电缆传送编码新闻图片，说明图像可以被离散表示和传输。
2. 数字计算机、存储和显示设备发展，使复杂图像运算成为可能。
3. 航天图像校正推动实际处理技术发展。
4. 医学成像、遥感、天文和工业检测拓展了应用。
5. 计算能力提高，使图像处理进入日常设备和智能系统。

学习重点是**数据数字化与计算能力共同推动图像处理**，无需将导入页中的全部历史日期和当代产品名称作为理论重点。

数字数据可以精确复制，但复制传播过程中永不失真有前提：数据本身必须完好，且不经历有损压缩、错误传输或其他改变数值的操作。采样和量化造成的信息损失不会因为数字存储而消失。

## 1.4 不同成像源及其用途

| 成像方式    | 观测信息或主要特点     | 应用             |
| ------- | ------------- | -------------- |
| 伽马射线    | 与放射性辐射分布相关    | 核医学、天文观测       |
| X射线     | 不同材料对射线的衰减差异  | 透视、CT、工业无损检测   |
| 紫外及荧光   | 特定物质的吸收或激发发光  | 显微观察、工业检测      |
| 可见光     | 人眼可感知的反射或发射光  | 摄影、显微、身份识别     |
| 红外      | 特定红外波段的反射或热辐射 | 遥感、夜间观察、热成像    |
| 太赫兹     | 特定材料的透射与响应差异  | 安检示例           |
| 微波雷达    | 主动发射后获取回波     | 地形遥感、部分天气条件下成像 |
| 无线电与磁共振 | 磁场和射频激励下的响应   | MRI、射电天文       |
| 超声      | 声波回波的时间与强度    | 内部结构成像         |
| 电子显微    | 电子与样品的相互作用    | 微观结构观察         |
| 计算机合成   | 几何、物理或生成模型的输出 | 仿真、图形生成        |

图像不局限于可见光照片。只要数据可按空间位置组织为阵列，就可以使用许多共同的图像处理方法；但数值的物理含义、噪声和分辨率必须分别理解。

<a id="section-1-5"></a>
## 1.5 图像处理系统与处理流程

### 1.5.1 硬件与软件组成

$$
\text{场景与能量源}\rightarrow\text{传感器与数字化}\rightarrow
\text{计算与算法}\rightarrow\text{显示、存储或传输}.
$$

系统通常包括采集设备、数字化设备、处理器、软件、存储、显示以及网络。处理器可以是CPU、GPU或专用硬件；选择取决于实时性、功耗和计算量。

### 1.5.2 主要处理任务的区别

| 任务 | 要解决的问题 | 典型输出 |
|---|---|---|
| 图像增强 | 让有用内容更容易观察或分析 | 增强图像 |
| 图像复原 | 根据退化模型估计较接近原始状态的图像 | 去模糊、去噪后的估计 |
| 几何校正与配准 | 消除位置、尺度、角度或形变差异 | 对齐图像及映射关系 |
| 图像融合 | 结合多幅图像的互补信息 | 融合图像或特征 |
| 图像压缩 | 减少存储或传输数据量 | 编码数据 |
| 图像分割 | 划分目标与区域 | 掩膜、标签图、边界 |
| 形态学处理 | 操作形状与连接结构 | 轮廓、骨架、填孔结果 |
| 特征提取与描述 | 将图像或目标变成可分析的描述 | 特征向量或描述子 |
| 检测与分类 | 判断对象在哪里、是什么 | 位置、类别、置信度 |
| 图像理解 | 解释对象、关系及场景含义 | 语义描述或决策 |

**增强与复原**的区别在于：增强偏向任务效果；复原通常显式建立退化模型，例如$g=h*f+n$，再估计$f$。

分类主要给出类别；检测还要给出位置；语义分割对像素赋类别；实例分割进一步区分同类的不同对象。图像理解的范围更广，不能仅等同于逐像素分类。

### 1.5.3 三个层次

1. 低层处理：图像输入、图像输出，如滤波和增强。
2. 中层分析：从图像中提取区域、特征或对象属性。
3. 高层理解：结合知识解释对象关系和场景。

这些层次可以反馈连接，不是所有系统都严格按单向流水线执行。

<a id="section-1-6"></a>
## 1.6 数据量与学科关系

未压缩图像的数据量约为：

$$
B=MNCb\quad\text{bit},
$$

其中$C$为通道数。$1920\times1080$的8位灰度图像约为$1.98\ \mathrm{MiB}$，RGB图像约为其3倍。视频再乘帧率和时长，因此压缩与高效计算非常重要。

图像处理需要微积分、线性代数、概率统计、信号处理和程序设计。计算机图形学常从模型生成图像；计算机视觉常从图像推断场景。它们有联系，但不是在一般条件下能够互相精确逆转的两种过程。

<a id="section-1-7"></a>
## 1.7 本章自测

1. **数字图像的两个离散化对象是什么？** 空间位置与强度，分别对应采样与量化。
2. **把照片锐化一定提高真实性吗？** 不一定，它可能制造过冲并放大噪声。
3. **图像增强与图像分割的输出有何不同？** 前者通常仍是图像，后者通常是区域标签或边界。
4. **红外图像上显示为红色的区域一定发出红光吗？** 不一定，显示颜色可能来自伪彩色编码。
5. **本章学习目标**：能为一个实际问题说明输入是什么、要得到什么、哪类处理合适。

## 附：符号约定

| 符号 | 含义与约定 |
|---|---|
| $f(x,y),g(x,y)$ | 输入、输出图像；默认$x$是行索引，$y$是列索引 |
| $M,N$ | 图像行数与列数；$0\le x<M,\ 0\le y<N$ |
| $L=2^b$ | 灰度级总数；$b$位图像的合法整数灰度为$0,\ldots,L-1$ |
| $r,s$ | 灰度变换的输入、输出数值；若使用$[0,1]$归一化会明确指出 |
| $h,w$ | 空间滤波核；通常$h$表示卷积核，$w$表示滑动相关模板 |
| $F(u,v),H(u,v)$ | 图像与空间核的傅里叶变换；$u,v$通常表示离散频率索引 |
| $\xi,\eta$ | 有量纲或归一化的空间频率，用来区别于频谱数组下标 |
| $*$、$\odot$ | 分别表示卷积、逐元素相乘；矩阵乘法另行说明 |
| $j$ | 虚数单位，$j^2=-1$ |
| $P,Q$ | 补零后图像的尺寸 |

傅里叶变换采用**正变换不归一化，逆变换除以样本总数**。
