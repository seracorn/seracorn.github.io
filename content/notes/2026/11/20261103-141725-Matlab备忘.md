## 数据流和尺寸

```text
SCM 三分量磁波形 ─┐
EFD 三分量电波形 ─┼→ TSeries → 时间重采样 → FAC → 分窗 FFT → 谱矩阵 → SVD
HPM 背景磁场向量 ─┤                                             ↓
卫星位置向量 ─────┘                           PSD、极化、波矢方向、坡印廷参数
                                                               ↓
HPM 磁场模长 → gyro → fcp                 强度掩膜 → result(i)
LAP A311 → Ne                                           ↓
                                      绘图副本 D → 截取 → 9 个面板 → 导出
```

| 数据 | 形式 | 关键含义 |
|---|---|---|
| `timeline` | `Nt×1` 数值列向量 | SVD 窗口中心的 Unix 秒 |
| `freqline` | `Nf×1` 数值列向量 | 频率，Hz |
| `Bpsd/Epsd/ThetaSVD/...` | `Nt×Nf` | 行对应 timeline，列对应 freqline |
| `Ne` | `Nne×2` | `[Unix时间, 电子密度]`，本项目标签为 m⁻³ |
| `fcp` | `Nhpm×2` | `[Unix时间, 质子回旋频率Hz]` |
| 旧式向量数组 | `N×4` | `[Unix时间, x, y, z]` |
| `TSeries` | 对象 | `.time` 保存时间，`.data` 保存数据 |
| `GM` | `Nhpm×3` | 当前主程序为 `[MLT, HPM磁纬, L]` |
| `h(j,i)` | 图形句柄 | 第 i 个日期、第 j 个面板 |
| `cbHandles(j,i)` | 色标句柄 | 对应面板已创建的色标 |

本笔记中的 `irf_*` 和 `irf.*` 来自 IRFU。带点的 `irf.*` 是 MATLAB 包函数；`Read_ZH_*`、`droma_*`、`gyro` 是项目辅助函数。

## 1. 找文件与读取数据

### dir / fullfile / h5read / h5info

```matlab
files = dir(fullfile(rootpath, folder{i}, 'SCM', ...
    ['CSES_01_SCM_2_L02_A2_' Orbit '*.h5']));
file = fullfile(files(1).folder, files(1).name);
UT = h5read(file, '/UTC_TIME');
info = h5info(file);  % 查看实际数据集名称和尺寸
```

- `dir` 返回结构体数组，常用字段为 `.folder`、`.name`。
- `fullfile` 按系统路径规则拼接目录和文件名。
- `h5read` 读取指定数据集；读取函数通过转置将文件维度整理为后续处理所需的行列布局。
- `files(1)` 越界时，先检查 `dir` 的匹配结果及文件路径。
- 日期建议用 `folder={'20190514','20220314'}`，取字符串用 `folder{i}`。
- `Orbit` 使用字符形式，例如 `'070940'`，保留前导零。

### Read_ZH_SCM_v0

```matlab
[tB, fB, Bpower, Bx, By, Bz, GM_B, Geo_B, Alt_B] = ...
    Read_ZH_SCM_v0(dataPath, Orbit, tint);
```

当前版本在 `dataPath/SCM/` 匹配 `SCM_2_L02_A2` 文件。读取 A241/A242/A243 的 `_P` 功率谱和 `_W` 波形，按 `tint` 截取。

`tB` 最终返回 Unix 秒；`GM_B`、`Geo_B` 都按经度、纬度排列。`Bpower` 来自文件中的功率谱，`Bpsd` 来自后续 SVD 流程中的 FFT。读取的波形块随后展开为连续向量。

### Read_ZH_EFD_v0

```matlab
[tE, fE, Epower, Ex, Ey, Ez, GM_E, Geo_E, Alt_E] = ...
    Read_ZH_EFD_v0(dataPath, Orbit, tint);
```

当前版本在 `dataPath/EFD/` 匹配 `EFD_2_L02_A1` 文件，读取 A121/A122/A123。

返回 **9 项**，其中第 8 项为地理经纬度，第 9 项为高度。

### Read_ZH_HPM_1Hz_ICD

```matlab
[tH, B0_ts, GM_H, Geo_H, Alt_H] = ...
    Read_ZH_HPM_1Hz_ICD(dataPath, Orbit, tint);
```

当前函数硬编码查找 `dataPath/HPM_3/CSES_01_HPM_5_L02_A2_...h5`。读取 A221/A222/A223 三分量，并经 `GEOPACK_BSPCAR` 转为地理笛卡尔分量；返回的 `B0_ts` 是三分量 `TSeries`。

这个接口使用 HPM_5 三分量构建 FAC 的背景场方向。使用 HPM_6 标量 A211 计算 fcp 时，另行读取该数据集。

### UTCtoUT / UTCtoUT_ICD

```matlab
calendar = UTCtoUT_ICD(UT(:));
tUnix = irf_time(calendar, 'vector6>epoch');
```

把 `yyyymmddHHMMSSFFF` 转成 `N×6` 的 `[年 月 日 时 分 秒]`，秒包含毫秒。

`UTCtoUT` 按字符串分割读取时间；`UTCtoUT_ICD` 按字符矩阵逐行解析。各读取函数已按数据方向安排调用，解析结果统一交给 `irf_time` 转为 Unix 秒。

## 2. 时间转换：irf_time / EpochTT / epoch2iso / irf.tint

### irf_time

语法：`out = irf_time(in, '输入格式>输出格式')`。

| 本项目用法 | 含义 |
|---|---|
| `irf_time(utc,'utc>epochtt')` | UTC 字符串 → EpochTT 对象 |
| `irf_time(calendar,'vector6>epoch')` | 六列日期 → Unix 秒 |
| `irf_time(calendar,'vector6>epochtt')` | 六列日期 → EpochTT |
| `irf_time(tUnix,'epoch>epochtt')` | Unix 秒 → EpochTT |
| `irf_time(tObj,'epochtt>epoch')` | EpochTT → Unix 秒 |

这里的 `epoch` 是 IRFU 的 Unix/ISDAT 时间：从 1970-01-01 起计的秒数。

```matlab
tObj = irf_time('2019-05-14T22:10:00.000Z', 'utc>epochtt');
tUnix = tObj.epochUnix;
```

### EpochTT 与 .epochUnix

`EpochTT` 封装时间数组，`.epoch` 保存其内部编码。用 `.epochUnix` 提取 Unix 秒，再用于绘图、数组拼接和时间截取。

先提取时间，再整理为列向量：

```matlab
HPM_unix = HPM_epoch.epochUnix;
result(i).fcp = [HPM_unix(:), fp(:)];
```

对象相减得到秒间隔，加数值秒构造新时间。主程序据此用首尾时刻和样本数量重建均匀时间轴。

### epoch2iso

```matlab
utcText = epoch2iso(tUnix);
```

Unix 秒 → ISO UTC 字符串。主程序用它给 `irf.tint` 提供起止时间。

### irf.tint

```matlab
Tint = irf.tint('2019-05-14T22:05:00Z', '2019-05-14T22:10:00Z');
Tint = irf.tint(epoch2iso(t0), epoch2iso(t1));
```

返回包含起止时刻的 EpochTT 区间，供 `irf_zoom` 使用。读取函数和本笔记的 `irf_tlim` 示例使用数值区间 `[t0 t1]`。

### datetime / char

```matlab
dateText = char(datetime(tUnix(1), 'ConvertFrom','posixtime', ...
    'TimeZone','UTC', 'Format','yyyy-MM-dd'));
```

用于生成 UTC 日期标题。

## 3. TSeries：irf.ts_vec_xyz / droma_ts_vec_xyz / irf.ts2mat

```matlab
tObj = irf_time(tUnix(:), 'epoch>epochtt');
B_ts = irf.ts_vec_xyz(tObj, [Bx(:), By(:), Bz(:)]);
M = irf.ts2mat(B_ts);          % [Unix时间 Bx By Bz]
Bmag = B_ts.abs.data;          % 向量模长
```

- `irf.ts_vec_xyz(time,data)`：时间长度 N，数据 `N×3`，构造向量时间序列。
- `droma_ts_vec_xyz`：本地副本与当前 `irf.ts_vec_xyz` 的核心构造方式相同。
- `TSeries(epoch,data,'vec_xyz')`：上述工厂函数内部的底层构造调用。
- `irf.ts2mat`：把标量或向量 TSeries 转成第一列为 Unix 秒的普通矩阵。
- `B_ts.time`：时间对象；`B_ts.data`：分量；`B_ts.abs.data`：模长，单位沿用输入数据。

以 Unix 秒构建时间序列时，按示例先用 `irf_time(...,'epoch>epochtt')` 生成时间对象，再传入构造函数。

<a id="tlim"></a>
## 4. irf_tlim：按时间截取数据

```matlab
Y = irf_tlim(X, [t0 t1]);
[Y, idx] = irf_tlim(X, [t0 t1]);
```

对第一列为 Unix 时间的普通矩阵，`irf_tlim` 返回区间内的数据行，`idx` 返回这些行在原数组中的索引。当前实现按 `t >= start`、`t < end` 判断，并为两元素区间形式加入微小的边界容差。

```matlab
Ne_part = irf_tlim(D.Ne, [t0 t1]);
[tPart, idx] = irf_tlim(D.timeline(:), [t0 t1]);
Bpart = D.Bpsd(idx, :);
```

`Bpsd` 的时间坐标存放在 `timeline` 中，因此先截取 `timeline`，再用返回的 `idx` 选择功率谱行。

对于带 `.t` 的结构体，函数同步截取第一维与 `.t` 长度一致的字段。本项目的 `result` 包含谱图、Ne 和 HPM 三套时间轴，各组数据分别按自己的时间坐标截取。

| 操作位置 | 实际效果 |
|---|---|
| SVD 前截取输入波形 | 在选定区间内重新建立窗口并计算 |
| SVD 后、绘图函数前截取 `D` | 保留完整计算，减少图形对象的数据量 |
| 绘制完整数据后再 `irf_zoom` | 调整显示范围，保留完整图形数据 |

## 5. 重采样与坐标变换

### irf_resamp

```matlab
E_on_B = irf_resamp(E, B);          % E 对齐到 B 的时间轴
E_on_B = irf_resamp(E, B, 'linear');
```

E、B 可采用 `[t,x,y,z]` 数组。第一参数是待处理的数据，第二参数提供目标时间轴。

本机默认策略：源采样率超过目标约两倍时做窗口平均，否则插值；显式指定插值方法后走插值。SVD 函数选择把低采样率的那组插值到高采样率时间轴。

### irf_convert_fac

```matlab
Efac = irf_convert_fac(E, B0, xyz);
Bfac = irf_convert_fac(B, B0, xyz);
```

背景场三分量 B0 与卫星位置 xyz 确定 FAC：

- z：沿背景磁场 B0。
- y：沿 z × 卫星位置向量。
- x：沿 y × z。

函数内部通过重采样对齐背景场、位置与待转换向量。

内部重要函数：

```matlab
bhat = irf_norm(B0);        % 归一化向量，保留时间列
crossVec = irf_cross(A, B); % 向量叉乘，带时间列的版本
```

`irf_norm` 输出单位方向向量。向量模长用 `B_ts.abs.data` 提取，或对三分量矩阵 B 计算 `sqrt(sum(B.^2,2))`。

### GEOPACK_BSPCAR

```matlab
[Bx,By,Bz] = GEOPACK_BSPCAR(theta,phi,Br,Btheta,Bphi);
```

球坐标磁场分量 → 笛卡尔磁场分量。`theta` 是余纬，`phi` 是经度，均为弧度。当前 HPM reader 使用 `Br=-A223`、`Btheta=-A221`、`Bphi=A222`。

### gap_long_lat_r2cart / sph2cart

```matlab
xyz = gap_long_lat_r2cart(lonDeg, latDeg, radius);
[x,y,z] = sph2cart(lonDeg*pi/180, latDeg*pi/180, radius);
```

前者接受角度，后者接受弧度。输出长度单位与 radius 相同。

主程序有两个不同用途：

- `radius=1.0`：转换到 SM 并求 MLT/L 时用的单位球位置。
- `radius=6370.4+Alt_hpm`：FAC 用的卫星位置，按当前代码以 km 表示。

### irf.geocentric_coordinate_transformation

```matlab
xyzSM = irf.geocentric_coordinate_transformation([tUnix(:),xyzGEO], 'GEO>SM');
```

时间相关的地心坐标变换；输出仍是 `[t,x,y,z]`。函数也支持向量 TSeries。

### xyz_to_lat_mlt_L

```matlab
[lat,MLT,L,R] = xyz_to_lat_mlt_L(xyzSM(:,2:4));
```

输入 SM 坐标，长度单位为地球半径 Re；输出纬度、磁地方时、偶极 L 和半径。当前主程序以单位半径计算 L，并用 HPM 文件中的磁纬构造 `GM`。

## 6. EB_FFT_SVD_YJ_V3：FFT、谱矩阵、SVD

### 接口

```matlab
[timeline,freqline,Epsd,Bpsd,Planarity,Ellipticity, ...
 ThetaSVD,PhiSVD,Dop3d,Poynting_Flux,Poynting_Theta,Poynting_Phi] = ...
    EB_FFT_SVD_YJ_V3(Ewave_ts,Bwave_ts,Btotal_ts,Rgeo_ts);
```

接受 TSeries，也接受 `[Unix时间,x,y,z]` 数组。四个输入依次是电波形、磁波形、背景磁场、卫星位置。函数内将 TSeries 转为数值矩阵后分析。

| 参数 | 当前默认值 | 实际作用 |
|---|---:|---|
| `'nopfft'` | 8192 | 每个 FFT 窗口的样本数 |
| `'steplength'` | 4096 | 相邻窗口前进的样本数；默认重叠一半 |
| `'bin_freq'` | 7 | 频域平滑使用的频点数 |

当前平滑权重 `aa` 固定为 7 点，配套参数为 `bin_freq=7`。FFT 点数和窗口步长共同决定时频分辨率。可选参数写法：

```matlab
% 设置 FFT 窗口、推进步长和频域平滑宽度
[t,f,Ep,Bp] = EB_FFT_SVD_YJ_V3(E,B,B0,R, ...
    'nopfft',8192,'steplength',4096,'bin_freq',7);
```

### 核心步骤与 MATLAB 函数

| 函数/表达式 | 在核心代码中的用途 |
|---|---|
| `fft(x,nopfft)/nopfft` | 对加窗后的单分量波形做 FFT 并归一化 |
| `conj` | 取复共轭，构造自谱/互谱 |
| `real`、`imag` | 提取谱矩阵实部、虚部 |
| `repmat`、`sum` | 将平滑权重作用于相邻频点并求和 |
| `squeeze` | 移除长度为 1 的维度，如 `1×6×3` → `6×3` |
| `[U,W,V]=svd(A,'econ')` | 经济型奇异值分解，`A=U*W*V'` |
| `atan2d(y,x)` | 计算带象限的角度，单位为度 |
| `sqrt`、`sign`、`abs` | 模长、旋向符号、绝对值 |
| `zeros` | 预分配时频矩阵 |
| `isnan`、`any` | 检查分解矩阵是否含 NaN |

每个频点的磁场谱矩阵实部与虚部上下拼接为 `6×3` 矩阵 A。`W` 中的奇异值按大小排序；代码用 `V` 的第 3 列求波法线方向。输出角度描述波法线在 FAC 中的方向。

当前窗函数由 `0.08 + 0.46*(1-cos(...))` 构造，FFT 后取前半段频率。频率间隔为 `Sr/nopfft`，时间窗口步长为 `steplength/Sr`。

### 输出与计算公式

| 输出 | 代码实际含义 |
|---|---|
| `timeline` | 每个窗口中心的 Unix 秒 |
| `freqline` | 单边频率坐标，Hz |
| `Epsd/Bpsd` | 三个分量自功率谱之和，尺寸 `Nt×Nf` |
| `Planarity` | `1-sqrt(W33/W11)` |
| `Ellipticity` | `(W22/W11)*sign(磁互谱虚部)` |
| `ThetaSVD` | 相对 FAC z 轴的角度，并折叠到 0–90° |
| `PhiSVD` | FAC 平面中的方位角，并配合 Theta 折叠调整至 −180–180° |
| `Dop3d` | 由磁谱矩阵计算的三维极化度 |
| `Poynting_Flux` | E/B 互谱构造的坡印廷向量模长，单位由 E、B 的输入单位决定 |
| `Poynting_Theta/Phi` | 坡印廷向量在 FAC 中的极角/方位角，度 |

`Ellipticity` 的符号由磁互谱虚部和 FAC 约定共同确定。`ThetaSVD` 将相反方向的波法线统一折叠到 0–90°，保留波法线与背景场的锐角。

主程序的两行：

```matlab
Poynting_para = cosd(Poynting_Theta);
Poynting_perp = abs(sind(Poynting_Theta));
```

这两项是无量纲方向因子。将其乘以采用统一单位计算的 `Poynting_Flux`，即可得到对应的能流分量。

<a id="gyro"></a>
## 7. gyro：质子回旋频率 fcp

```matlab
[fp,fce,flhr,fco,fche] = gyro(Btotal_ts.abs.data);
```

输入 B 为 nT，函数内乘 `1e-9` 转为 T；输出频率为 Hz。

| 输出序号 | 本地函数变量名 | 实际计算 |
|---|---|---|
| 1 | `fpe`，主程序接成 `fp` | **质子回旋频率** `e*B/(2*pi*mp)` |
| 2 | `fce` | 电子回旋频率幅值 |
| 3 | `flhr` | 本代码采用 `fce*sqrt(me/mp)` 计算 |
| 4 | `fco` | 单电荷 O⁺ 回旋频率，约 fp/16 |
| 5 | `fche` | 单电荷 He⁺ 回旋频率，约 fp/4 |

第一个输出在函数内命名为 `fpe`，在主程序中接收为 `fp`；它对应质子回旋频率 fcp。

```matlab
HPM_unix = HPM_epoch.epochUnix;
fcp = [HPM_unix(:), fp(:)];
```

`gyro_freq2 = [HPM_unix, fche, fco]` 保存 He⁺ 和 O⁺ 的回旋频率曲线。质子曲线使用 `D.fcp`，由主程序统一叠加到 8 个谱图。当前绘图函数中的 `gyro_freq` 参数保留在接口中，内部叠加语句已注释。

## 8. IRF 绘图函数

### irf_plot：线图或叠加曲线

```matlab
irf_plot(h(1,i), D.Ne, 'color','black','linewidth',1.2);
hold(h(2,i),'on');
irf_plot(h(2,i), D.fcp, '--', 'color','black','linewidth',1.5);
```

## 13. 常见报错速查

| 现象 | 本项目应先检查 | 处理方向 |
|---|---|---|
| `SCM(1)` / `HPM(1)` 索引越界 | `dir` 是否为空；目录、文件模式、Orbit；实际函数版本 | 检查 `which ... -all` 及真实文件名 |
| `D=result(i)` 超过 1 | result 只有一组却按两组循环 | 按已保存结果数量循环：`1:numel(result)` |
| `EpochTT/epochUnix 输入参数太多` | 是否写了 `.epochUnix(:)` | 先取到普通变量，再 `(:)` |
| `date_svd` 未定义 | 导出文件名是否依赖旧变量 | 明确指定文件名或从 result 构造 |
| `tShowStart/tShowEnd` 未定义 | 是否只改了 zoom，未放截取代码 | 使用上一节完整片段，或恢复完整 timeline 起止 |
| `输出参数太多`，发生在 droma_plot | 函数头是否声明 `hc` 返回值 | 与 `cbHandles=...` 的调用保持一致 |
| 谱图颜色条重复/遮挡 | 是否再次创建色标 | 复用绘图函数返回的 hc |
| fcp 线错位 | 是否用普通 plot 加绝对 Unix 时间 | 使用 `irf_plot` 并明确轴句柄 |
| 显示区间较短，绘图仍卡顿 | 是否只改了 XLim/irf_zoom | 绘图前截取时频矩阵 |
| HPM 文件匹配失败 | reader 固定要求 HPM_5，实际是否只有 HPM_6 | 按 HPM_5 三分量或 HPM_6 标量产品选择读取方式 |
| 二次加载后跑脚本又开始算 | 是否从 `clear;clc` 开始执行 | 单独运行绘图区或独立缓存脚本 |

| 位置                | 当前实现与影响                                             | 处理位置或方法                                                               |
| ----------------- | --------------------------------------------------- | --------------------------------------------------------------------- |
